# 🎓 Student Management System

A simple **Console-Based Student Management System** developed using **Core Java**. This project demonstrates CRUD (Create, Read, Update, Delete) operations using **ArrayList**, along with Object-Oriented Programming (OOP) concepts and menu-driven programming.

---

# ✨ Features

- Add Student
- View All Students
- Update Student Details
- Delete Student
- Menu-Driven Console Interface
- In-Memory Data Storage using ArrayList

---

# 📋 Functionalities

### ➕ Add Student

- Student ID
- Student Name
- Student Age
- Student Course

### 📖 View Students

Displays all student records stored in memory.

### ✏️ Update Student

Updates an existing student's details using Student ID.

### ❌ Delete Student

Deletes a student record using Student ID.
